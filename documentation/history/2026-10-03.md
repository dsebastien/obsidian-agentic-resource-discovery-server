# 2026-10-03

## Secrets moved to Obsidian SecretStorage (BR-6c)

Why: the bearer token and hosted API key sat in plaintext in `data.json`, which travels with the vault (git, Syncthing, cloud). Same issue as dsebastien/obsidian-cli-rest#13.

- Settings keep only names: `server.bearerTokenSecretName`, `searchBackend.apiKeySecretName`. Legacy `server.bearerToken` / `searchBackend.apiKey` stay in the schema as optional read-only bootstrap fields; new `legacySecretMigratedAt`.
- `src/app/settings/secrets.ts` (pure, `SecretStore` port, fully unit-tested): `migrateLegacySecrets` (per device, idempotent, keeps plaintext for other devices, 60-day purge), `ensureBearerTokenSecret` (generate on fresh install only; `missing` never regenerates), `rotateSecret` / `selectSecretName` / `clearSecret` / `removeLegacySecretCopies`, `resolveBearerToken` / `resolveEmbeddingApiKey`.
- Use-time reads: `RouterDeps.bearerToken` and `HttpEmbedderConfig.apiKey` are getters; `RegistryController` takes `RegistrySecrets`. `requiresRestart` compares `apiKeySecretName`; `projectMcpConfigAffected` compares `bearerTokenSecretName`, and Regenerate re-syncs `.mcp.json` explicitly. `.mcp.json` still gets the token (user's opted-in client config), now read from SecretStorage.
- Settings tab: `SecretComponent` pickers for the token and API key, copy/regenerate/clear buttons, "missing on this device" warning rows, **Remove plain-text copy now** button. `isBlankToken` and `.ard-token-field` removed.
- minAppVersion already 1.13.0 (SecretStorage needs 1.11.4).

Decisions: legacy plaintext kept 60 days rather than deleted on first migration, so a device that has not started the new version yet still bootstraps (user requirement: no device must need re-entry). A value already in SecretStorage wins over the legacy copy. Clearing the API key clears the name too (applies to all devices, like before).

Needs manual verification in a live vault: secret pickers render and persist the name; regenerate updates `.mcp.json`; a second device with synced `data.json` migrates on start; the warning rows show when a secret is missing.

Open: a token regenerated on device A does not reach device B's SecretStorage (device-local by design); B keeps its own value until set there.
