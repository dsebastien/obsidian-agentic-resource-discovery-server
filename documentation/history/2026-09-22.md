- New `src/app/scan/representative-queries.ts`, shared by both enrichers: `firstClause` + `toQueryCase` (description opening in query case, acronyms kept), `extractTriggerPhrases` (quoted phrases verbatim, from `when_to_use` first, then `description`; else an unquoted `Triggers: a, b` list; else the object of `Use when the user asks about X`), `capabilityQuery` (`vault.links.check` → `check links`, refused when subject = verb), `isNovelPhrase`, `finalizeQueries` (case-insensitive dedupe, cap 5, undefined below 2 — BR-10).
- Skill order: opening clause, trigger phrases, capability (only when no query already carries it), `argument-hint` modes. Agents unchanged in output, now built on the shared helpers.
- Real-data smoke over the vault's 421 skills: 0 `Help with`, 0 doubled words; `user-business` (`business.context.context`, no triggers) drops to one candidate and therefore omits the field, as BR-10 requires.
